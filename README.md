# Rowad Al-Teb Specialty Hospital Website

A complete responsive hospital website built with React.js, Vite, Tailwind CSS, and REST API integration.

The project was developed to provide patients with a clear and user-friendly digital experience for exploring hospital services, doctors, technologies, partners, and outpatient booking options.

## Features

- Responsive design for desktop, tablet, and mobile
- Arabic and English language support
- RTL / LTR layout switching
- Doctor listing and specialty-based browsing
- Outpatient booking flow
- Dynamic doctor and specialty data
- REST API integration
- API fallback handling
- Partners / contracted companies section
- Hospital technologies and services pages
- Contact information and communication sections
- Reusable React components
- Responsive navigation
- Clean and organized healthcare UI

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- JavaScript
- Axios
- React Router
- i18next
- REST APIs
- Git
- GitHub

## Booking Flow

The website includes an outpatient booking experience where users can:

- Select a medical specialty
- View available doctors
- Check schedule information
- Complete a booking form

The booking interface was designed to be simple, responsive, and easy to use.

## API Integration

The frontend connects to backend services to manage dynamic content such as:

- Medical specialties
- Doctors
- Schedules
- Booking-related data

API requests and fallback data handling are used to maintain a stable user experience.

## Responsive Design

The website was designed with responsive behavior across multiple screen sizes, with attention to:

- Mobile navigation
- Flexible layouts
- Responsive cards
- Proper spacing
- RTL / LTR compatibility
- Preventing horizontal overflow

## Project Purpose

This project represents a real-world healthcare website developed for Rowad Al-Teb Specialty Hospital, focusing on usability, responsive design, API integration, and multilingual support.
